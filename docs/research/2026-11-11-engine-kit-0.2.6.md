# engine-kit 0.2.6 (2026-11-11)

Versão de correção. O que muda para quem usa o kit:

- **Troca do mcp-gateway sem derrubar os clientes:** antes de trocar os arquivos, `ensureGateway` pede `POST /admin/drain` com `{reason, waitMs}` e espera a resposta, que o daemon só dá depois de drenar as chamadas em curso. Só cai no SIGTERM se o daemon não drenar. Detalhe em `2026-11-11-drain-do-gateway-antes-de-trocar-os-arquivos.md`.
- **Pasta de dados do gateway resolvida na chamada:** `MCP_GATEWAY_DATA_DIR` definido depois do import vale para porta, token e drain.
- **`ensure` avisa em vez de calar:** descritor vindo de cache vencido (registry fora do ar) e ponteiro `cli.json` quebrado viram uma linha de aviso.
- **Publish:** conflito da mescla da main na develop restrito a manifest/README é resolvido aplicando a mesma mudança (`2026-11-11-conflito-do-readme-na-mescla-do-publish.md`), e o manifest é validado contra o schema antes de qualquer push.
- **Manifest embarcado:** vox-engine 0.33.1, que é a última release publicada.

Lente de feature irmã: `2026-11-11-lente-feature-irma-engine-kit-0.2.6.md`.

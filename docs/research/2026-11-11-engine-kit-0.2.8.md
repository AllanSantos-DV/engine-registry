# engine-kit 0.2.8 (2026-11-11)

Versão de manifest. `smart-design` 0.2.3 (release `smart-design-v0.2.3` com `.whl` de 198148 bytes, `.sha256` e `.sig`, mesma chave pública do app). O manifest guarda só a versão: o nome do asset, o checksum e a assinatura saem dos modelos `{version}`/`{asset}` da entrada, então não há hash por versão para copiar. A linha do README muda no mesmo commit.

`node kit/verify-release.mjs --app smart-design` baixa os três arquivos como um consumidor e confere sha256 e assinatura ed25519.

O código do kit não mudou em relação à 0.2.7; o pacote do npm sobe porque leva o `manifest.json` embarcado.

# engine-kit 0.2.7 (2026-11-11)

Versão de correção. O que muda para quem usa o kit:

- `kit/publish-base.ps1` roda no Windows PowerShell 5.1 como no pwsh 7. Com `$ErrorActionPreference = "Stop"`, o 5.1 transforma o stderr de um exe nativo em `NativeCommandError` mesmo com `2>$null`; a consulta `gh release view` de uma release ainda inexistente (saída 1, mensagem no stderr) abortava o publish antes de criar a release. As duas chamadas ao `gh` que descartam o stderr (`gh api user` e `gh release view`) passam por `Invoke-GhQuiet`, que baixa a preferência para `Continue` só durante a chamada; quem decide é o `$LASTEXITCODE`.
- `manifest.json`: `smart-design` 0.2.2 (release `smart-design-v0.2.2` com `.whl`, `.sha256` e `.sig`, mesma chave pública). `node kit/verify-release.mjs --app smart-design`: sha256 e assinatura ed25519 conferem.

## Prova

`tests/test-publish-base-ps.mjs` roda o script de verdade (assinatura real com chave descartável, `gh` falso no PATH, sem rede) em `powershell.exe` e em `pwsh.exe`: release inexistente segue até o `gh release create`; release já existente aborta antes de criar. Sem a correção o caso `powershell.exe` reprova com `NativeCommandError` na saída; o `pwsh.exe` já passava.
